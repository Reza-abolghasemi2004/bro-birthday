# BROTHER 29

**29 Years. One Bond. Always Brothers.**

یک هدیهٔ دیجیتال شخصی برای تولد ۲۹ سالگی برادرم؛ از یک پیام کوتاه شروع می‌شود، با شش آرزوی واقعی ادامه پیدا می‌کند و با «لبخند یادت نره، داداش!» به پایان می‌رسد.

رابط فارسی و کاملاً راست‌چین، تم سرمه‌ای/طلایی، تصویرسازی‌های SVG اختصاصی و حرکت‌های آرام. بدون React، بک‌اند، دیتابیس، CDN، آنالیتیکس یا صدای خودکار. تمام فونت‌ها و منابع داخل پروژه هستند؛ در زمان اجرا هیچ درخواست خارجی انجام نمی‌شود.

## اجرا

### روش اول: Node.js

Node.js نسخهٔ ۲۲ یا بالاتر پیشنهاد می‌شود:

```sh
npm run dev
```

آدرس: `http://localhost:3000`

برای **صرفاً اجرای سایت** حتی به نصب پکیج هم نیاز نیست؛ سرور توسعه فقط از ماژول‌های داخلی Node استفاده می‌کند. تغییر پورت:

```sh
PORT=8080 npm run dev
```

سرور به `0.0.0.0` متصل می‌شود و روی شبکهٔ محلی/پیش‌نمایش نیز قابل مشاهده است. این سرور صرفاً فایل‌های استاتیک را ارائه می‌کند و بک‌اند برنامه نیست.

### روش دوم: Python

از ریشهٔ مخزن اجرا کنید:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

به علت استفاده از ES Modules، باز کردن `index.html` با دوبار کلیک و پروتکل `file://` مناسب نیست؛ از یکی از سرورهای استاتیک بالا استفاده کنید.

### انتشار

فایل `index.html` و پوشه‌های `assets/`، `css/` و `js/` را بدون تغییر ساختار روی هر میزبان استاتیک قرار دهید؛ از جمله GitHub Pages. build لازم نیست. مسیر منابع نسبی است و انتشار زیر یک مسیر فرعی نیز کار می‌کند. پوشه‌های `node_modules/`، `tests/` و `scripts/` برای انتشار لازم نیستند.

آفلاین در این پروژه یعنی **بدون نیاز به اینترنت یا سرویس ثالث**: با یک سرور محلی کار می‌کند و پس از بارگذاری، تعویض فصل‌ها نیازی به شبکه ندارد. Service Worker یا تضمین بازکردن دوبارهٔ سایت آنلاین پس از قطع کامل اتصال پیاده‌سازی نشده است.

فایل تصویری حجیم یا پوشهٔ خالی وجود ندارد؛ تصویرسازی‌ها برداری، اختصاصی و داخل ماژول‌ها هستند.

## تغییر متن آرزوها

فایل `js/scenes.js` را ویرایش کنید. هر عضو آرایهٔ `scenes` این فیلدها را دارد:

- `id`: شناسهٔ یکتای انگلیسی برای آدرس فصل و استایل اختصاصی.
- `label` و `short`: نام فارسی کامل و کوتاه فصل در پیمایش.
- `english`: زیرعنوان کوچک انگلیسی.
- `pretitle`: متن اختیاری بالای تیتر.
- `title`: تیتر اصلی؛ با `<em>` می‌توان بخش رنگی و با `<br>` شکست سطر ساخت.
- `paragraphs`: آرایهٔ پاراگراف‌ها؛ هر عضو یک پاراگراف مستقل است.
- `aside`: یادداشت کوتاه اختیاری زیر متن.
- `next`: عنوان اختیاری دکمهٔ بعدی.
- `closing`: جملهٔ پایانی اختیاری.
- `accent`، `glow` و `art`: رنگ تأکیدی، نور محیط و نوع تصویرسازی.

برای برجسته‌کردن کلمات از `<strong>` استفاده کنید. متن‌ها HTML محلی و قابل اعتماد هستند؛ دادهٔ ناشناس کاربر یا محتوای دریافتی از اینترنت را بدون پاک‌سازی وارد این فیلدها نکنید.

متن دکمهٔ لبخند در `js/interactions.js`، امضای برادر و جملهٔ ثابت انگلیسی در `index.html` قرار دارند.

## تغییر رنگ‌ها

در `css/variables.css` متغیرهای `--background`، `--surface`، `--navy`، `--gold`، `--soft-gold`، `--white`، `--emerald` و `--rose` را ویرایش کنید. برای هر فصل، `accent` یکی از نام‌های رنگ موجود و `glow` سه عدد RGB است؛ مثلاً:

```js
accent: 'emerald',
glow: '50,201,151',
```

رنگ‌های پایهٔ رابط از متغیرها می‌آیند. stopهای طیف طلایی و رنگ کندل‌های SVG در `artwork.js` و `forex-scene.js` تعریف شده‌اند؛ در تغییر کامل پالت، آن‌ها را هم هماهنگ کنید. کنتراست متن را پس از تغییر دوباره تست کنید.

## تنظیم حرکت‌ها

- زمان خروج بین فصل‌ها: `--transition-duration` در `variables.css` (واحد `ms`).
- زمان ورود متن: `--entrance-duration` در همان فایل.
- فاصلهٔ ورود هر خط: `--delay`های ساخته‌شده در `navigation.js`؛ صحنهٔ شروع عمداً تأخیر بیشتری دارد.
- حرکت‌های محیطی، رسم خطوط و رشد کندل: `animations.css`.
- تعداد ذرات: حلقهٔ `createParticles` در `animations.js`؛ مقدار فعلی **۱۸** است و در موبایل حداکثر ۸ عدد دیده می‌شود.
- جشن کوتاه: ۱۸ نقطه، بدون حلقهٔ JavaScript دائمی؛ پس از حدود دو ثانیه حذف می‌شوند.

خروج از هر فصل، انیمیشن‌های محتوای قبلی و تایمرهای موقت را پاک می‌کند. نمودار با CSS رسم می‌شود و تایمر یا دادهٔ زنده ندارد. قفل کوتاه انتقال مانع تداخل کلیک‌های سریع می‌شود. پس‌زمینهٔ مشترک فقط یک بار ساخته می‌شود.

تنظیم سیستمی `prefers-reduced-motion` رعایت می‌شود. دکمهٔ «کمی آرام‌تر» نیز حرکت‌ها را قطع می‌کند و ترجیح را به‌صورت اختیاری در `localStorage` نگه می‌دارد؛ مسدودبودن ذخیره‌سازی باعث خرابی سایت نمی‌شود.

## افزودن فصل جدید

۱. یک شیء مشابه فصل‌های موجود، **بین اولین و آخرین عضو** آرایهٔ `scenes` اضافه کنید. شروع و پایان باید عضو اول و آخر بمانند.

۲. برای آن `id` یکتا، `label`، `short`، `english`، `title`، `paragraphs`، `accent`، `glow` و `art` مشخص کنید. برای تصویرسازی موجود می‌توان از `birthday`، `forex`، `love`، `brothers`، `family` یا `smile` استفاده کرد؛ `null` یعنی بدون تصویرسازی.

۳. اگر طرح جدیدی نیاز است، تابع SVG آن را در `artwork.js` و حالت متناظر را در `renderArtwork` اضافه کنید.

۴. فهرست، تعداد و مقدار پیشرفت خودکار از داده استخراج می‌شوند. چیدمان فعلی مسیر فصل‌ها برای شش مورد تنظیم شده؛ تعداد ستون‌های `.chapter-list` در `responsive.css` و متن‌های «شش آرزو» در `index.html` و `navigation.js` را با تعداد جدید هماهنگ کنید.

۵. تست‌ها سناریوی شش‌فصلی و تعداد مشخص نمودارها را بررسی می‌کنند؛ در صورت تغییر داستان، انتظارهای آن‌ها را نیز به‌روزرسانی کنید.

## غیرفعال‌کردن یک افکت خاص

- **ذرات:** فراخوانی `createParticles` در `app.js` را بردارید؛ یا `.particles { display: none; }` اضافه کنید.
- **تصویرسازی فصل:** مقدار `art` آن فصل در `scenes.js` را `null` کنید.
- **حرکت نمودار:** انیمیشن `.candle` را `none` و برای `.draw-line` مقدار `stroke-dashoffset: 0` بگذارید.
- **جشن لبخند:** فراخوانی `celebrate` و تایمر `sparkTimer` در تابع `smile` را حذف کنید؛ پیام همچنان مستقل کار می‌کند.
- **تمام حرکت‌ها به‌صورت پیش‌فرض:** کلاس `motion-paused` را روی `body` قرار دهید و مقدار اولیهٔ `setMotion` در `interactions.js` را نیز هماهنگ کنید تا در شروع بازنویسی نشود.

## پیمایش و دسترس‌پذیری

- شروع، قبلی، بعدی، شروع مجدد و پرش مستقیم به هر فصل.
- کلید **چپ = بعدی** و **راست = قبلی** مطابق RTL؛ `Tab` و `Enter` برای دکمه‌ها.
- محتوای بلند بدون قفل اسکرول، در موبایل و دسکتاپ قابل خواندن است.
- تیتر فصل پس از تغییر فوکوس می‌گیرد و وضعیت فصل در ناحیهٔ زنده اعلام می‌شود.
- فوکوس مشخص، لینک پرش به متن، نوار پیشرفت دارای ARIA و عناصر تزئینی مخفی از صفحه‌خوان.
- نمودارهای فارکس دادهٔ واقعی یا توصیهٔ مالی نیستند؛ این موضوع روی همان فصل نوشته شده است.
- هیچ صدایی پخش نمی‌شود و اطلاعات شخصی جمع‌آوری نمی‌شود.

## تست و بررسی موبایل

نصب ابزارهای **فقط توسعه** و مرورگر تست:

```sh
npm ci
npx playwright install --with-deps chromium
npm test
```

تست‌ها با Playwright/Chromium روی دسکتاپ و شبیه‌سازی موبایل اجرا می‌شوند. سناریوها: تمام فصل‌ها، پایان و شروع مجدد، کلیدها، فوکوس، کلیک‌های سریع، پاک‌شدن افکت‌ها، کاهش حرکت، ذخیرهٔ ترجیح توقف حرکت، قطع شبکه پس از بارگذاری، نبود منابع خارجی و خطاهای بارگذاری، و اسکن axe برای WCAG A/AA در تمام قاب‌ها.

عرض‌های **۳۲۰، ۳۹۰، ۷۶۸، ۱۰۲۴ و ۱۴۴۰** پیکسل برای جلوگیری از اسکرول افقی بررسی می‌شوند. این‌ها تست مرورگر و شبیه‌سازی موبایل هستند، نه ادعای تست روی گوشی فیزیکی یا تمام مرورگرها. تست خودکار جای ارزیابی انسانی صفحه‌خوان را نمی‌گیرد.

اگر مرورگر از قبل در محیط نصب شده باشد، می‌توان مسیر آن را داد:

```sh
CHROMIUM_EXECUTABLE_PATH=/path/to/chromium npm test
```

بررسی دستی پیشنهادی:

۱. DevTools را باز کنید، Device Toolbar را روشن و اندازهٔ ۳۹۰×۸۴۴ و سپس ۳۲۰×۷۰۰ را انتخاب کنید.

۲. تمام فصل‌ها را با دکمه‌ها بخوانید؛ متن بلند، دکمهٔ آخر صفحه و نبود سرریز افقی را بررسی کنید.

۳. در بخش Rendering، گزینهٔ `prefers-reduced-motion: reduce` را فعال و مسیر را دوباره طی کنید.

۴. بعد از بارگذاری در بخش Network گزینهٔ Offline را فعال کنید؛ فصل‌ها باید همچنان کار کنند.

۵. با `Tab` و کلیدهای چپ/راست پیمایش کنید و Console را برای خطا بررسی کنید.

۶. برای گوشی واقعی، سایت را روی یک میزبان HTTPS استاتیک قرار دهید یا آدرس IP محلی رایانه روی پورت ۳۰۰۰ را در همان شبکه باز کنید.

## مجوز فونت‌ها

فونت Vazirmatn و Cormorant Garamond با مجوز SIL Open Font License داخل `assets/fonts/` همراه پروژه هستند. فونت فارسی در این پروژه به‌صورت متغیر و محلی بارگذاری می‌شود؛ فونت لاتین نمایشی برای عدد 29 و زیرنویس‌های ظریف استفاده شده است.
